# Mi proyecto
Este es un taller o proyecto practico para descubrir el funcionamiento de Git y Git Hub
# Instalacion
Para desarrolar esta actividad se nesecitaa tener instalado Git
## comandos utilizados 
init:Lo utilice para crear e iniciar un repositorio de Git dentro de una carpeta de mi taller para convertirla en un repositorio de Git y empezar a registrar cualquier cambio que haga a partir de ese momento.
git add:Lo utilice para seleccionar que archivos queremos guardar en el siguiente commit.
git commit:Este comando sirve para guardar los cambios en el historial del proyecto de GitHub, ademas acompanado de un mensaje tipo etiqueta para agregar mi propio comentario.
git push:Este comando me permite subir los cambios y commits que tenemos en el computador a nuestro repositorio de GitHub.
git status:Lo utilice ya que permite saber en que estado se encuentra nuestro proyecto y de preferencia lo utilixo constantemente para saber exactamente que archivo estoy modificando, ademas para saber cuales no eh guardado en mi repositorio.
git diff:Este comando me sirvio para cuando quiero revisar con mas detalle el antes y el despues para ver que cambios se hicieron en un archivo antes de guardarlos en un commit.
git log:Me permitio ver los commits que se han realizado anteriormente con el tiempo y revisar el historial del proyecto.
git restore:Me sirvio para quitar cambios y en gran parte equivocaciones que hicimos en un archivo y volver a una version anterior cuando todavia no hemos hecho el commit permitiendome descartar estos cambios.
